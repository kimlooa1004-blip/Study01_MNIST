# 대화기록

클로드와 주고받은 대화를 과제 제출용으로 모아두는 폴더다.

## 파일 이름 규칙

```
YYYY-MM-DD_주제.md
```

예) `2026-10-01_대화기록-폴더-추가.md`

하루에 여러 번 대화했으면 주제를 다르게 적어 파일을 나눈다.

## 저장하는 방법

1. 클로드 코드 화면에서 대화 내용을 복사한다.
2. 위 이름 규칙에 맞춰 이 폴더에 `.md` 파일로 붙여넣는다.
3. 아래 틀을 맨 위에 적어 언제, 무엇을 했는지 남긴다.

```markdown
# 2026-10-01 · 주제

- 날짜: 2026-10-01
- 작업 브랜치: claude/inspiring-ramanujan-tzjsku
- 한 줄 요약: 무엇을 왜 했는지

## 대화

**나**

...

**클로드**

...

## 결과

- 바뀐 파일:
- 커밋:
```

## 주의

- 파일은 UTF-8로 저장한다.
- 학번·이름 외의 개인정보(이메일, 비밀번호, 토큰)는 지우고 올린다.
