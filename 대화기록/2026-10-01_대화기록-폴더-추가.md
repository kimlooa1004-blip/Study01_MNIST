- 날짜: 2026-10-01
- 작업 브랜치: `claude/inspiring-ramanujan-tzjsku`
- 한 줄 요약: 클로드와의 대화를 과제 제출용으로 남기기 위해 `대화기록/` 폴더를 만들었다.

## 대화

**나**

여기에 폴더 추가 어떻게 해?

**클로드**

"여기에"가 두 가지로 읽혀서 둘 다 안내했다.

1. **저장소에 새 폴더를 추가하는 경우** — 깃은 빈 폴더를 추적하지 않으므로 폴더 안에 파일이 하나는 있어야 한다.

   ```bash
   mkdir -p 새폴더이름
   touch 새폴더이름/.gitkeep   # 내용이 아직 없을 때 자리표시용
   git add 새폴더이름
   git commit -m "새폴더이름 폴더 추가"
   git push -u origin claude/inspiring-ramanujan-tzjsku
   ```

2. **클로드 코드 세션에 다른 폴더를 보이게 하는 경우** — 터미널에서 `/add-dir <경로>`를 쓴다.
   단 이 세션은 클라우드 컨테이너라서 컨테이너 안의 경로만 추가할 수 있고, 내 PC의 폴더는 안 된다.
   다른 깃허브 저장소를 붙이려면 `소유자/저장소` 이름을 알려주면 된다.

**나**

교수님이 여기에 폴더 추가해서 너랑 내 대화를 저장하려고 하시는 것 같아.

**클로드**

그 용도면 저장소에 기록용 폴더를 두는 게 맞다.
`대화기록/` 폴더를 만들고 파일 이름 규칙·저장 방법을 적은 `README.md`를 넣었다.
이 파일이 그 첫 번째 기록이다.
`CLAUDE.md`의 폴더 구조 표와 `README.md`의 폴더 구조에도 새 폴더를 같이 적었다.
